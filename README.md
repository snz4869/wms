# Interactive Warehouse Layout Simulator (PrimaWMS)

Static Web Application (React + Vite + Tailwind CSS) untuk visualisasi tata letak gudang 2D Top-Down SVG, inspeksi rak bertingkat (`L1–L3`), kalkulasi kapasitas volumetrik (`m³`), simulasi operasional (`Receiving`, `Picking`, `Relocation`), serta analitik dan ekspor CSV.

## Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

## Build untuk Production (Vercel / Cloudflare Pages)

```bash
npm run build
```
